Platzreservierung für die Bibliothek

Java-Webanwendung (JSP, PostgreSQL), mit der Besucher Arbeitsplätze reservieren und Administratoren den Betrieb verwalten.

Teamprojekt 2021Java · JSP · PostgreSQLHochschule Ludwigshafen
Prototyp ausprobieren Artikel und Folien

Worum geht es?

BiBViSiT löst ein alltägliches Problem: Arbeitsplätze in der Hochschulbibliothek sind knapp. Besucher sehen die Platzübersicht, reservieren einen Platz für einen Tag und können Nachrichten senden. Administratoren pflegen Plätze, Besucher, Reservierungen und weitere Administratoren. Das Projekt folgt dem Muster View, Controller und Model mit JDBC-Zugriff auf PostgreSQL.

Frontend

Startseite, Platzübersicht, Reservierung pro Tag, Kontaktformular, Anmeldung

Backend

Plätze, Besucher, Reservierungen, Nachrichten und Administratoren verwalten

Datenbank

Tabellen Admin, Place, Visitor, Reservation, Messages

Überarbeitung

Verbindungsdaten aus Umgebungsvariablen, keine Zugangsdaten im Code

Prototyp: Platzübersicht ausprobieren

Eine Browser-Demo des Kernablaufs: Tag wählen, freien Platz anklicken, reservieren. Die Daten bleiben nur auf dieser Seite im Speicher. Im Original läuft das gegen PostgreSQL.

Grenzen und Einordnung

Die Originalanwendung enthielt Klartext-Passwörter und weitere Altlasten. In der überarbeiteten Fassung wurden Zugangsdaten entfernt, die Git-Historie kann aber noch alte Stände enthalten. Für einen echten Betrieb fehlen unter anderem Passwort-Hashing, Eingabeprüfung und Tests. Die Demo oben ersetzt die Anwendung nicht.
